# cms_etl

cms_etl is a lightweight ETL framework featuring a menu-driven console environment and scripting tools used to expedite ETL processes.

In addition to a comprehensive table-editing/macro-building environment with support for multiple concurrent database connections,
there are utilities for fuzzy matching across columns/tables, setting types, formatting addresses, etc.

The macro export functionality doubles as a human-readable DSL for examining and editing ETL flows and allows for fully-processed datasets to easily be used directly in scripts.
